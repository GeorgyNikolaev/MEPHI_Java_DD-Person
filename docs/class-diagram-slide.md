# Диаграмма классов для слайда

Концептуальная схема backend (упрощённая, для презентации).  
На слайд удобнее вставлять **вариант 1** (блоки) или скопировать **вариант 2** (ASCII) в фигуры PowerPoint.

---

## Вариант 1 — блоки (Mermaid)

Скопируйте в [mermaid.live](https://mermaid.live) → Export PNG/SVG → вставка на слайд.

```mermaid
flowchart TB
    subgraph presentation["Слой представления"]
        UI["Клиент React<br/>авторизация · генерация · история · персонажи · избранное"]
    end

    subgraph api["Слой REST API"]
        CTRL["Контроллеры<br/>Auth · Generations · Characters · Portraits · Favorites"]
    end

    subgraph services["Слой сервисов"]
        SVC["Сервисы<br/>Auth · Generation · Character · Favorite · Portrait"]
    end

    subgraph generation["Подсистема генерации"]
        GEN["PromptBuilder<br/>Async Pipeline<br/>GigaChat Adapter"]
    end

    subgraph data["Данные и внешние системы"]
        PG[("PostgreSQL")]
        RD[("Redis")]
        FS[("Файлы JPG")]
        GC["GigaChat API"]
    end

    UI --> CTRL
    CTRL --> SVC
    SVC --> GEN
    SVC --> PG
    SVC --> RD
    GEN --> PG
    GEN --> FS
    GEN --> GC
```

## Вариант 3 — доменные сущности (если нужна именно «классовая» модель данных)

```mermaid
classDiagram
    direction LR

    class Пользователь {
        email
        имя
    }

    class Персонаж {
        имя
        параметры
        последнийПортрет
    }

    class ЗапросГенерации {
        статус
        промпт
    }

    class Портрет {
        файлJpg
        размер
    }

    class Избранное {
        датаДобавления
    }

    Пользователь "1" --> "N" Персонаж : владеет
    Пользователь "1" --> "N" ЗапросГенерации : создаёт
    ЗапросГенерации "1" --> "0..1" Портрет : результат
    Персонаж "0..1" --> "1" Портрет : lastPortrait
    Пользователь "1" --> "N" Избранное : сохраняет
    Избранное "N" --> "1" Портрет : ссылка
```

## Подпись под слайдом (1 строка)

**Архитектура DD Person:** React-клиент → REST API → сервисы → async-генерация (GigaChat) → PostgreSQL, Redis и файловое хранилище.
