# Сценарии использования

## UC-1: Регистрация и вход

**Актор:** новый пользователь  
**Цель:** получить доступ к генерации портретов

1. Пользователь открывает `/register`, вводит email, пароль, имя.
2. Backend создаёт запись в `users`.
3. Frontend выполняет login, получает JWT в HttpOnly cookies.
4. Пользователь попадает на `/dashboard`.

**Результат:** аутентифицированная сессия без хранения токена в localStorage.

---

## UC-2: Генерация портрета «с нуля»

**Актор:** авторизованный пользователь  
**Цель:** получить JPG портрета по описанию и параметрам

1. Пользователь на `/generate` заполняет описание, роль, вселенную, настроение, шкалы.
2. `POST /generations` → запись `PENDING`, промпт собран на сервере.
3. Асинхронный pipeline вызывает GigaChat, сохраняет JPG.
4. UI polling показывает статус и изображение.
5. При ошибке — `FAILED`, доступен retry.

**Результат:** портрет в `portrait_artifacts` + файл в `storage/portraits/`.

---

## UC-3: Шаблон персонажа и повторная генерация

**Актор:** авторизованный пользователь  
**Цель:** не вводить параметры заново

1. Пользователь создаёт персонажа на `/characters` (имя + параметры).
2. На странице персонажа нажимает «Сгенерировать портрет».
3. `POST /characters/{id}/generations` — параметры берутся из шаблона.
4. После успеха обновляется `characters.last_portrait_id`.

**Результат:** новый `generation_request` связан с `character_id`.

---

## UC-4: Избранное

**Актор:** авторизованный пользователь  
**Цель:** сохранить понравившийся портрет

1. На странице результата генерации — «В избранное».
2. `POST /portraits/{id}/favorite` → запись в `favorite_portraits`.
3. Список на `/favorites`.
4. Удаление — `DELETE /portraits/{id}/favorite`.

**Результат:** избранные портреты без понятия «кампания».

---

## UC-5: История и повтор при сбое

**Актор:** авторизованный пользователь  
**Цель:** просмотреть прошлые попытки и повторить

1. `/history` — список с фильтром по статусу.
2. Открытие детали — параметры, промпт, ошибка.
3. При `FAILED` — `POST /generations/{id}/retry` с теми же параметрами.

**Результат:** новый запрос генерации, старый остаётся в истории.
